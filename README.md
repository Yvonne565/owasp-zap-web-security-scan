# owasp-zap-web-security-scan
# Web Application Vulnerability Assessment Using OWASP ZAP

## Overview
This project documents a hands-on web application security assessment conducted using OWASP ZAP. The objective was to identify common web vulnerabilities, analyze security risks, and propose remediation strategies.

## Tools Used
- OWASP ZAP
- Vulnerable Web Application (DVWA)
- Kali Linux
- Firefox Browser

## Methodology
1. Target application setup
2. Automated scanning using OWASP ZAP
3. Analysis of discovered vulnerabilities
4. Documentation of findings and remediation steps

## Key Findings
- Cross-Site Scripting (XSS)
- SQL Injection
- Missing Security Headers
- Insecure Cookies
